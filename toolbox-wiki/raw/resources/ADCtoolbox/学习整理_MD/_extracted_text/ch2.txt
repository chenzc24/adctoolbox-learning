                     Classes of Sampling
• Nyquist-rate sampling (fs > 2B)
   – Nyquist-rate data converters
   – In practice always slightly oversampled (e.g., by 2 or 4)
• Oversampling (fs >> 2B)
   – Oversampled data converters
   – Anti-alias filtering is often trivial
   – Oversampling also reduces quantization noise
       • More details to follow
• Subsampling (fs < 2B)
   – Exploit aliasing to down-convert high-frequency signals
   – See [Pekau & Haslett, JSSC, 2005]

Quantization of an Analog Signal
                 • Vq: quantized voltage
                 • eq: quantization error
                 • eq = Vq - Vin


                 • Quantization step: D
                 • Quantization error has saw
                   tooth shape
                    – Bounded by [–D/2, +D/2]


                 • Ideally
                    – Infinite input range and
                       infinite number of
                       quantization levels

                                                 19
Quantization of an Analog Signal
                 • In practice
                    – Finite input range and finite
                       number of quantization
                       levels
                 • Quantization error grows out of
                   bounds beyond code
                   boundaries
                 • We define the full scale range
                   (FSR) as the maximum input
                   range that satisfies |eq|  D/2
                 • Overloading occurs when an
                   input outside the FSR is applied

      • LSB size (or width) –

      • Code width – The difference

        the code width W[k]=T[k+1]-

                             Summary
• Uniform distribution in general holds reasonably well, especially for
  random input
• However, it does not hold when:
   – The input is too small or DC that it spans only 1 or 2 quantization
     steps
   – The input is highly correlated with the sampling clock
   – The input is too large that it overloads the quantizer

                      NRZ vs. RZ DACs
• Advantage of NRZ DACs
   – Less high-frequency noise  less burden on the filter
   – Less sensitivity to clock jitter
   – Less requirement on slew rate
   – Less power (smaller unit current source)
• Disadvantage of NRZ DACs
   – Large inter-symbol interference
       • Unmatched rise and fall
