                   How to Oversample?
• How to oversample when the DAC digital input is at the Nyquist rate?
   – For an ADC whose input is continuous time, oversampling is easy
     as we can acquire the input at any given time instance
   – For a DAC, we only know the digital inputs at fixed time instances
• Several options
   – Perform an equivalent digital zero-order hold
        • Does this change the signal spectrum?
   – Linear interpolation between adjacent points
        • Does this distort the signal spectrum?
   – Adding zeros in between adjacent points and then digital LP
     filtering
        • Equivalent to sine wave reconstruction and then re-sampling

            Benefits of Digital Oversampling

• The design of the analog reconstruction filter can be much simpler
   – The first few images are removed by digital low pass filtering
   – Analog re-construction is equivalent to oversampling by infinity
• Oversampling allows quantization noise shaping!
• Given 24-bit digital data, we want to convert it to an analog signal:
   – Option #1: design a 24-bit DAC
        • Complicated, area/power consuming, cannot guarantee linearity
   – Option #2: design a 16-bit DAC, and only use the first 16-bit data
        • Less complicated, less area/power, but less accuracy, nonlinear
   – Option #3, design a 1-bit DAC, and use noise shaping to move the
      truncation (quantization) error out of signal band
        • Easy to design, area/power efficient, and guaranteed linearity!

                 Problems with 1-bit DAC
• The DAC output has large jumps
   – It is sensitive to clock jitter
   – It is hard to guarantee linearity due to inter symbol interference,
     slewing, etc
       • 1-bit DAC is guaranteed linear only when we do not consider
           dynamic errors
• It would be nice if we can reduce the step size and apply some
  “digital” filtering before the DAC output goes to the analog
  reconstruction filter
