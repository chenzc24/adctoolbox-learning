                          Reducing tDAC
• Without redundancy, each bit needs to settle to the target resolution
   – For a 10-bit SAR, need to allocate 7t
• With redundancy, each bit only needs to settle to the redundancy range
   – Incomplete settling error can be recovered later
   – For a 10-bit SAR with 5% redundancy, only need 3t

                      Prior 2b/cycle works
• All requires extra C-DAC or R-DAC to generate reference voltages
   – Requires extra area & power
   – Vulnerable to gain mismatch
   – Requires extra control logics


• Can we achieve 2b/cycle without any extra DAC?
   – 1 differential DAC generate 3 comparison voltage?
       • Prior works use only differential-mode signal
       • Add one more dimension: common-mode
