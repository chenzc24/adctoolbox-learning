                                   Tones

• Key observations:
   – The quantization error is deterministic, not random, if there is no
     randomness (e.g., dither and thermal noise) added into the loop
   – The quantization error is correlated with the input
• In a first-order delta-sigma modulator, the quantization error is highly
  correlated with the input, and thus, its spectrum is not white, but contains
  spurious tones.
• This is fundamentally due to the nonlinear behavior of the quantizer.
• It is generally difficult to analyze the tonal behavior for an arbitrary input
• Let us take a look at a simple DC input to get an intuitive understanding

                Idle Tone Considerations

• Idle tones are problematic in audio applications
   – The human ear can detect tones ~20dB below the noise floor
• There are several way to reduce idle tones:
   – External dither
       • Add a random signal at the quantizer input to “whiten”
         quantization noise
   – Thermal noise dither
       • Electronic noise from integrators can dither the quantization
         noise for free
   – Multi-bit quantizer and DAC
   – Higher order modulators
       • Naturally produce “more random” quantization error
         sequences

                               Stability
• The feedback loop can be unstable!
• Note that the quantizer is nonlinear and its gain depends on the input
  amplitude
   – We need to guarantee loop stability under all possible quantizer
     gains
• In general, it is hard to analyze the stability for a nonlinear system
• Designers usually rely on:
   – Stability analyses using the linear model
   – Heuristics
   – Intensive time-domain simulations using the nonlinear model




                                                                           43
                        Stability Heuristics

• Single-bit
   – 1st-order modulator is stable with the standard integrator
        • It can go unstable if additional gain is provided in the loop
   – 2nd-order modulator is stable for inputs with magnitude < D/20. It is
      “likely” to be stable for slow varying input with magnitude < 0.8·D/2,
   – Lee's criterion: modulator is "likely" to be stable if max[He(w)]<1.5
• Multi-bit
   – The stability for a multibit modulator is in general much better than
     that for a single-bit modulator
   – A Nth-order modulator using an N+1 bit quantizer is stable for arbitrary
     inputs with amplitude less than half the quantizer input range

                     NTF Design Procedure

• Standard design procedure:
   – Choose order based on desired SQNR and OSR
   – Design NTF using filter approximations (e.g. Chebyshev2)
   – Make sure that NTF is realizable and satisfies Lee's stability criterion
   – Derive A(s) based on NTF
   – Evaluate performance and stability using time-domain simulations
   – Scale coefficients to limit integrator output swing
   – For details, see Delta-Sigma Data Converters, by Norsworthy, Schreier
      & Temes, Sections 4.4 and 5.6
• Can be automated
   – Delta-Sigma Toolbox for MATLAB by Richard Schreier
   – http://www.mathworks.com/matlabcentral/fileexchange/19-delta-
     sigma-toolbox

           NTF Design Example in Matlab (1)

% Specify parameters
L = 4, OSR = 50, StopBand = 70


% NTF synthesize
[b,a] = cheby2(L, StopBand, 1/OSR, 'high')


% Scale b(1) to 1 to ensure realizability; a(1)=1 by default
b = b/b(1);


% Check stability using Lee’s criteria
NTF = filt(b, a, 1)
bode(NTF)


% Solve for A(z)
A = inv(NTF) - filt(1,1,1)

                       Nonlinear OTA Gain

• A signal-dependent OTA gain is more problematic
• It causes A(z) to be nonlinear, which causes the mixing of the quantization
  noise and the signal and the self mixing of the quantization noise, which
  leads to large in-band distortion and SQNR loss
• We usually over design the OTA gain so that its nonlinearity has negligible
  effect

• Advantages for discrete-time (DT) DS ADCs
   – The SC filters are very accurate and linear
   – The difference equations are independent of the clock rate.

   – CT modulators have intrinsic anti-aliasing property
   – CT modulators can run at higher clock rate
      • It does not need to settle!
