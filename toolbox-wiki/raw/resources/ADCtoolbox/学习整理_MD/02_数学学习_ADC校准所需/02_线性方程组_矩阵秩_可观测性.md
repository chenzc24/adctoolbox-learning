# 线性方程组、矩阵秩与可观测性

## 线性方程组在校准中的形式

校准常写成：

A x = y

其中 x 是未知参数，例如 bit weight、stage gain、offset；A 是已知观测矩阵，例如每次转换的码字组合；y 是测得或构造的目标输出。

如果未知量有 N 个，至少需要 N 条独立信息才能唯一求解。

## 什么叫独立信息

两条方程如果只是倍数关系，本质上只提供同一条信息。矩阵秩 rank(A) 表示 A 中真正独立的信息数量。

若 rank(A) < 未知量个数，则问题秩亏，说明有些参数无法从当前观测中区分出来。

## ADC 中的秩亏例子

假设某两个 bit 总是同时为 0 或同时为 1，那么输出变化无法区分到底是 w1 变了还是 w2 变了。即使采集很多数据，也只是重复同一种组合，无法估计两个独立权重。

这就是为什么校准需要“丰富激励”。输入信号、dither、伪随机序列的作用之一，就是让不同权重以不同组合出现，使矩阵 A 满秩或条件更好。

## 可观测性

可观测性回答：某个误差是否会在输出中留下可区分痕迹？如果误差不影响观测，或者和另一种误差表现完全一样，就无法单独校准。

例如整体 gain error 和参考电压误差在某些测试中可能表现相似；如果没有额外参考，就很难区分。

## 条件数

即使矩阵满秩，也可能“接近秩亏”。这时小噪声会导致解大幅波动。条件数越大，求解越不稳定。

校准算法不仅要追求方程数量，还要追求观测矩阵的良好条件。dither 的一个重要价值就是改善矩阵结构。

## 学习重点

校准不是“方程越多越好”，而是“独立且信息丰富的方程越多越好”。当你看到 dither、双频输入、多组校准信号时，应想到它们是在增强可观测性。
