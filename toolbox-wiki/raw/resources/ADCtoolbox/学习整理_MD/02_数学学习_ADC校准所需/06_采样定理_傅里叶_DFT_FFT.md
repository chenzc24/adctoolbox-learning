# 采样定理、傅里叶、DFT 与 FFT

## 采样为什么会导致频谱复制

时域采样可以理解为原信号乘以冲激序列。时域相乘对应频域卷积，而冲激序列的频谱仍是冲激序列。因此原始频谱会以 fs 为间隔周期复制。

如果复制后的频谱互相重叠，就发生 aliasing。

## Nyquist 条件

若信号最高频率为 B，为避免基带频谱重叠，采样率需要满足：

fs ≥ 2B

这不是说高于 2B 就万事大吉。真实系统还需要 anti-alias filter，因为任何超过 Nyquist 的外来频率都可能折叠回信号带内。

## DFT 的作用

DFT 把有限长度离散序列分解到一组离散频率网格上。N 点 DFT 的频率间隔为：

df = fs / N

这解释了为什么采样点越多，频率分辨率越高。

## 频谱泄露

如果输入频率不是 DFT 网格频率，能量无法只落在一个 bin，会泄露到周围 bin。解决方法包括相干采样和窗函数。

相干采样要求采样窗口内包含整数个输入周期，常写成：

fin/fs = M/N

且 M 与 N 互质有助于让样本更均匀覆盖相位。

## FFT 是什么

FFT 不是新的变换，而是快速计算 DFT 的算法。它利用对称性和分治，把复杂度从 N^2 降到 N log N。

学习 ADC 不必先掌握 FFT 代码，但要理解 FFT 图中的 bin、频率分辨率、泄露和窗函数。

## 和 ADC 指标的关系

SNR、SNDR、SFDR、THD 等动态指标通常从频域得到。FFT 不是目的，它只是把输出码流中不同频率成分分开，让我们区分信号、谐波、噪声和杂散。
