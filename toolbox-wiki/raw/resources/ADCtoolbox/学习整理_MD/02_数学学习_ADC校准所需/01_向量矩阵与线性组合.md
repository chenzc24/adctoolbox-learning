# 向量、矩阵与线性组合

## 为什么 ADC 校准需要线性代数

很多 ADC 的数字输出可以写成“若干码字乘以若干权重再相加”。这正是线性组合。

例如 SAR ADC 中，每一位 bit 控制一个电容权重：

D = b1*w1 + b2*w2 + ... + bN*wN

Pipeline ADC 中，每一级的数字输出也有级间权重：

D = d1*w1 + d2*w2 + d3*w3 + ...

理想情况下 w_i 是二进制权重；真实情况下 w_i 有误差。校准就是估计真实 w_i。

## 向量的含义

向量可以看成一组数，也可以看成空间中的方向。在 ADC 校准中，更常见的是把一组 bit 或一组 stage output 写成向量：

b = [b1, b2, ..., bN]
w = [w1, w2, ..., wN]

输出就是内积：

D = b · w

这个式子很重要：一个转换结果给出的是“码字向量 b 在权重向量 w 上的投影”。

## 矩阵的含义

如果有很多次转换，每一次都有一组 bit，就可以把所有 bit 码字堆成矩阵 A：

A = 每一行是一组观测码字
x = 未知权重
y = 实际输出或参考输出

于是得到：

A x = y

这就是校准问题的基本形式。

## 线性组合的直觉

线性组合就是“用固定积木拼出结果”。如果积木权重准确，拼出的数字就准确；如果某个积木比理想大一点，所有使用这个积木的码字都会系统性偏大。

因此，校准不是逐个 code 修正，而是寻找底层积木的真实大小。

## 学习重点

不要把矩阵当成计算技巧。对 ADC 来说，矩阵 A 代表你给 ADC 施加过哪些激励、观察过哪些码字组合；未知 x 代表真实电路参数；y 代表你希望解释的观测结果。
