# MATLAB 基本观念：命令窗口、脚本和工作区

## MATLAB 是什么

MATLAB 的名字来自 Matrix Laboratory。它最自然的对象不是单个数，而是矩阵和数组。很多数学表达在 MATLAB 中可以直接写成接近公式的形式。

## 命令窗口

命令窗口适合临时计算。输入一行，马上得到结果。它像草稿纸，适合检查公式、看变量大小、快速试一个函数。

## 脚本 Script

脚本是按顺序执行的一组命令。脚本没有独立输入输出，运行时会使用并修改当前 workspace 中的变量。

脚本适合学习和整理流程，但大型代码中过度依赖脚本会让变量来源混乱。

## 工作区 Workspace

workspace 保存当前变量。学习 MATLAB 时要经常观察变量的 size 和 class，因为很多错误不是公式错，而是维度不对。

常用观察方式：

- whos：看变量列表、大小和类型。
- size(x)：看数组维度。
- length(x)：看最长维度长度。
- class(x)：看数据类型。

## 分号的作用

语句末尾加分号会禁止自动输出。不加分号会在命令窗口打印结果。学习时可以少加分号观察变量，正式脚本中通常加分号避免刷屏。

## 注释和 section

百分号 % 后面是注释。两个百分号 %% 常用于分节，方便分段运行脚本。

## 学习重点

把 MATLAB 看成“可执行的数学笔记”。你读代码时先不要逐行纠结语法，而要先判断这段代码在做什么数学操作：构造变量、变换维度、求解方程、频域分析、统计误差还是画图。
