# 绘图、文件读写与调试

## 绘图的作用

MATLAB 绘图不是装饰，而是理解数据的方式。ADC 学习中常见图包括时域波形、频谱图、误差直方图、DNL/INL 曲线和校准前后对比。

## 常见绘图函数

- plot：普通二维曲线。
- stem：离散序列图。
- histogram：直方图。
- semilogx / semilogy：对数坐标。
- xlabel、ylabel、title、legend、grid：图形标注。

## 文件读写

常见函数：

- load / save：MATLAB 数据文件。
- readmatrix：读取表格或文本数据。
- writematrix：写出矩阵。
- fopen / fread / fclose：低层文件操作。

## 调试

调试时最有用的问题：

1. 变量 size 是否符合预期？
2. 是否出现 NaN 或 Inf？
3. 索引是否越界？
4. 矩阵乘法维度是否匹配？
5. 是否把矩阵运算和点运算混淆？

## breakpoint

可以在 MATLAB 编辑器中设置断点，逐行运行，观察变量变化。对学习别人的函数非常有用。

## 学习重点

绘图和调试都是为了理解。你现在不需要搭建 ADC 实验，但应能读懂代码为什么画某张图，以及这张图对应哪种数学或指标。
