# ch4 Nyquist Rate DACs：理解 ADC 前必须知道的 DAC

## 学习目标

虽然你的主线是 ADC，但 DAC 是很多 ADC 架构内部的核心部件。SAR ADC 的电容阵列本质是 DAC，Pipeline ADC 每级都有 sub-DAC，校准中的“权重”也常来自 DAC 单元失配。

## DAC 的基本任务

DAC 把数字码映射为模拟电压或电流。理想情况下，每个 bit 对应确定权重。例如二进制 DAC 中，MSB 权重大，LSB 权重小，输出是各 bit 与权重的线性组合。

Vout = b0*w0 + b1*w1 + ... + bN*wN

真实 DAC 的问题在于 w_i 不可能完全理想。电阻、电容、电流源都有随机失配和系统误差。

## 常见 DAC 结构

### Resistor String DAC

用电阻串分压产生多个等间隔参考电压，再通过开关选择输出。优点是单调性好，缺点是面积和开关复杂度随位数增加明显。

### Binary Weighted DAC

每一位用二进制权重元件实现。结构直观，但 MSB 与 LSB 元件比例差异大，高位匹配要求严。

### R-2R DAC

用两种电阻值构造二进制权重，避免极大元件比例。但开关和电阻匹配仍会影响线性度。

### Current Steering DAC

用电流源阵列输出电流，适合高速 DAC。主要问题是电流源匹配、输出阻抗、开关瞬态和 glitch。

### Switched Capacitor DAC

用电容比实现权重，特别常见于 SAR 和 Pipeline ADC。优点是静态功耗低，和 CMOS 工艺兼容；缺点是电容失配、寄生电容、开关注入和建立误差。

## 静态误差和动态误差

静态误差包括 offset、gain、DNL、INL。动态误差包括建立时间、glitch、时钟馈通、开关注入和频率响应滚降。ADC 内部 DAC 的动态误差会影响每次比较或余差生成。

## 为什么 DAC 与校准强相关

在 SAR ADC 中，电容 DAC 权重不准会导致比较阈值不准。在 Pipeline ADC 中，sub-DAC 输出不准会导致余差错误。这些错误通常可以写成权重误差：

实际权重 = 理想权重 + 误差

校准的任务就是估计实际权重，然后在数字输出中使用实际权重而不是理想权重。

## 进一步展开：为什么 ADC 学习要理解 DAC

许多 ADC 的核心不是直接把电压变码字，而是不断构造一个模拟参考量和输入比较。这个模拟参考量往往由 DAC 产生。SAR 的每一步二分搜索靠电容 DAC；Pipeline 的每一级余差生成靠 sub-DAC；Sigma-Delta 的反馈回路也有 DAC。

DAC 误差会表现为参考电平不准。若第 k 个电平偏高，ADC 对应区间边界也会移动。于是 DAC 的静态线性问题变成 ADC 的 DNL/INL 问题。

二进制权重 DAC 最容易和校准数学连接。理想权重是 1/2、1/4、1/8...，实际权重由于元件失配变成这些值加误差。校准就是估计这些权重，而不是盲目相信设计值。
