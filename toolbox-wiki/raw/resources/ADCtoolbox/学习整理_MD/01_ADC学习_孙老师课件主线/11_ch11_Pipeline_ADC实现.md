# ch11 Pipelined ADC Implementation：Pipeline ADC 实现

## 学习目标

ch10 讲概念，本章讲实现。重点是 MDAC、开关电容余差放大、级间误差和数字校正。对学习校准来说，本章非常关键。

## 一个 Pipeline stage 的组成

典型 stage 包含：采样保持、sub-ADC、sub-DAC、减法器、余差放大器。实际电路中这些功能常合并在 MDAC 中。

MDAC 即 multiplying DAC。它一边根据 sub-ADC 结果产生 DAC 电压，一边对余差进行放大。

## 开关电容 MDAC

开关电容实现依赖电容比。采样相位把输入采到电容上，放大相位根据数字码把部分电容接到参考电压，同时通过反馈电容形成余差放大。

理想余差公式可写成：

Vres = G · (Vin - Vdac)

其中 G 由电容比决定。只要电容比不准，G 就不准；只要 DAC 电平不准，Vdac 就不准。

## 主要非理想

### 有限运放增益

闭环增益依赖运放有限开环增益。开环增益不足会造成增益误差，直接影响后级权重。

### 有限带宽和 slew rate

输出在半个时钟周期内必须建立到足够精度。建立不完全会产生动态误差。

### 电容失配

MDAC 增益和 DAC 权重都由电容比决定。电容失配会导致 DNL/INL 和级间权重错误。

### 运放噪声和 kT/C

噪声会降低 SNR。它不同于系统性权重误差，不能简单校准掉。

## 数字校正与冗余

Pipeline 常使用冗余编码，使某一级小范围比较错误不会立刻导致最终错误。但冗余只能容忍有限误差，不能无限补偿放大器饱和、严重非线性或后级 overload。

## 权重校准的核心形式

如果每一级输出码为 d_i，最终输出不应简单按理想二进制拼接，而应按实际权重相加：

Dout_corrected = Σ d_i · w_i_actual

w_i_actual 可以通过前台校准、后台校准、伪随机 dither、最小二乘等方法估计。

## 本章学习重点

Pipeline 校准不是脱离电路的数学问题。它校准的是 MDAC 增益、电容 DAC 权重、级间权重和余差路径误差。只有理解这些误差来自哪里，线性方程组和 dither 的意义才会清楚。

## 进一步展开：MDAC 是 Pipeline 校准的中心

MDAC 同时承担 DAC、减法器和放大器三个角色，因此它的误差会以多种形式进入最终输出。电容比决定反馈因子和 DAC 电平，运放决定闭环精度和建立速度，开关决定采样和电荷注入。

级间增益误差最适合用权重观点理解。理想情况下，第一级的某个 code 对最终输出贡献很大，后级 code 贡献逐级减小。如果第一级实际增益偏小，后级覆盖的真实输入范围就变了，简单二进制拼接会系统性错误。

数字冗余只能校正有限范围内的比较器错误和 residue 偏移。它不是替代模拟精度，而是降低某些局部错误对最终输出的敏感性。真正的增益、权重和非线性问题仍可能需要校准。
