# ADCToolbox Learner Toolbox Wiki

This directory is the sidecar LLM Wiki for learning ADCToolbox.

It is intentionally separate from the existing `adctoolbox-learning` course
content. Existing staged learning files are not moved, renamed, or rewritten by
this wiki. The wiki links to them when useful and keeps its own synthesis,
source notes, rigor notes, and operation log here.

## Directory Map

```text
toolbox-wiki/
  raw/resources/          # Imported source materials; treat as read-only
  schema/                 # Wiki rules and page templates
  logs/                   # Append-only operation history
  wiki/                   # LLM-maintained knowledge pages
  curriculum_bridge/      # Links between staged learning and the wiki
  index.md                # Top-level navigation
  progress.md             # Current learning state and protection rules
```

## Operating Principle

The staged course remains the learning path. This wiki is the compounding
knowledge layer: it accumulates cross-links, source-code mappings, mathematical
assumptions, engineering caveats, and answers worth preserving.

For maintenance rules, read `schema/WIKI_RULES.md` first.
