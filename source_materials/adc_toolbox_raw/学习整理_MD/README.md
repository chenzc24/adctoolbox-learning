# ADCtoolbox 学习整理说明

本目录是新增的学习整理输出，源文件全部保留在原位置，不移动、不删除、不覆盖。

## 三条学习主线

### 1. ADC 学习

目录：01_ADC学习_孙老师课件主线

以孙老师课件 ch1-ch17 为主线，每个唯一课件对应一个 Markdown 学习笔记。笔记不是课件复刻，而是扩展解释：增加背景、物理直觉、关键公式、非理想因素、与校准的连接、自检问题。

### 2. 数学学习

目录：02_数学学习_ADC校准所需

围绕 ADC 与校准补充数学基础，包括向量矩阵、线性方程组、矩阵秩、最小二乘、概率噪声、量化误差、采样傅里叶、卷积滤波和 dither。

### 3. MATLAB 学习

目录：03_MATLAB学习

MATLAB 只作为纯学习和读懂代码的语言材料，不作为 ADC 实验主线。重点是数组、矩阵、索引、点运算、函数、绘图、调试，以及如何读懂 ADC 资料中的 MATLAB 代码。
