# 数组、矩阵、索引与冒号

## 数组是 MATLAB 的核心

MATLAB 中最常见的数据是数组。标量是 1x1 数组，向量是一维数组，矩阵是二维数组，多维数组可以表示更多维度的数据。

## 行向量和列向量

行向量：

x = [1 2 3]

列向量：

x = [1; 2; 3]

空格或逗号分列，分号分行。很多线性代数运算对行列方向敏感。

## 索引从 1 开始

MATLAB 索引从 1 开始，不是从 0 开始。x(1) 是第一个元素。

二维矩阵 A(i,j) 表示第 i 行第 j 列。

## 冒号操作符

冒号是 MATLAB 中最重要的符号之一。

1:5 表示 [1 2 3 4 5]

1:2:9 表示 [1 3 5 7 9]

A(:,j) 表示第 j 列所有行。

A(i,:) 表示第 i 行所有列。

## 逻辑索引

可以用条件选择元素：

x(x > 0)

这表示取出 x 中大于 0 的元素。读 ADC 数据处理代码时，逻辑索引常用于选出某些 bin、某些 code 或某段范围。

## 预分配

循环中逐步扩展数组会慢。MATLAB 常先用 zeros、ones、nan 预分配空间。

例如：

y = zeros(1, N)

这表示先准备一个 1xN 的全零向量。

## 学习重点

读 MATLAB 代码时，第一件事是看维度。很多表达式表面像数学公式，但真正含义取决于变量是标量、行向量、列向量还是矩阵。
