# 流程控制、函数与匿名函数

## if / elseif / else

条件判断用于根据参数或数据状态走不同分支。例如如果输入频率未知，就自动估计；如果已提供，就直接使用。

基本结构：

if condition
    ...
elseif other_condition
    ...
else
    ...
end

## for 循环

for 用于固定次数循环。ADC 代码中常见用途包括遍历 harmonics、遍历 bit、遍历 stage、遍历 FFT bin。

for k = 1:N
    ...
end

## while 循环

while 用于条件满足时持续运行。优化搜索、迭代收敛、三分搜索等可能使用 while。

## function

函数有自己的输入输出，比脚本更清晰。

function y = f(x)
    y = x.^2;
end

读函数时先看函数头：输入是什么，输出是什么。再看主体如何从输入构造输出。

## 多输出函数

MATLAB 函数可以有多个输出：

[a, b] = func(x)

读代码时要注意某个函数返回的不一定只有一个结果。

## 匿名函数

匿名函数用于快速定义数学表达：

f = @(x) x.^2 + 1

这在拟合、优化、滤波器响应中常见。

## 学习重点

流程控制只是组织逻辑。读 MATLAB 代码时，不要被 for/if 吓住，要问：循环对象是什么？每次迭代在累计什么？条件分支对应哪种数学情况？
