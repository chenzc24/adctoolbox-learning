# ch3 Data Converter Performance Metrics：ADC 性能指标

## 学习目标

本章建立描述 ADC 好坏的语言。指标不是孤立数字，而是把真实传输曲线、噪声、失真和频谱表现压缩成可比较的量。

## 静态指标：看传输曲线

静态指标关心 DC 或低速输入下，输入电压和输出码之间的关系。

### Offset Error

Offset 是整体传输曲线在起点附近的平移。直观地说，输入为零或理想起始电压时，ADC 输出已经偏了。Offset 常可以通过数字减法修正，因为它像一个常数项。

### Gain Error

Gain error 是传输曲线斜率的错误。去掉 offset 后，如果满量程端点仍然不对，就是 gain error。它像一个比例系数错误，通常可以通过乘法或参考电压校准修正。

### DNL

DNL 描述每个 code width 和理想 LSB 的差异：

DNL[k] = (实际 code 宽度 / 理想 LSB) - 1

如果 DNL = 0，说明这个码宽度刚好理想。如果 DNL < -1，说明该码宽度为负或不存在，会产生 missing code。DNL 更像局部误差。

### INL

INL 描述实际传输曲线相对理想直线的累计偏差。它比 DNL 更像全局误差。DNL 是每一步台阶的局部宽度错误，INL 是这些局部错误累加后的整体形状错误。

## 动态指标：看频谱和噪声

动态指标关心输入正弦波时，输出频谱中能量如何分布。

### SNR

SNR 是信号功率与噪声功率之比。理想 N 位 ADC 的量化噪声模型给出近似公式：

SNR ≈ 6.02N + 1.76 dB

这条公式成立需要假设输入接近满量程正弦、量化误差均匀分布且与输入不相关。

### SNDR / SINAD

SNDR 把噪声和失真都算进分母，因此比 SNR 更接近真实可用精度。若非线性产生明显谐波，SNDR 会比 SNR 低。

### ENOB

ENOB 是用 SNDR 反推出“等效理想 ADC 位数”：

ENOB = (SNDR - 1.76) / 6.02

它不是实际 bit 数，而是综合噪声和失真后的有效精度。

### SFDR 和 THD

SFDR 关注最大杂散 spur 与信号之间的距离，常用于通信系统。THD 关注谐波失真总和，主要反映非线性。

## 指标之间的关系

Offset 和 Gain error 可以理解为低阶、可校正误差。DNL/INL 反映区间不均匀，更难校正。SNR 受噪声限制，THD/SFDR 受非线性限制，SNDR/ENOB 则把二者合并。

## 与校准的连接

校准通常优先处理可参数化的误差：offset、gain、权重误差、级间增益误差。DNL/INL 是校准效果最直接的静态观察对象；SNDR/ENOB 是校准是否提升动态表现的观察对象。

读完本章后，不要求记住所有电路细节，但要能把“模拟量如何被采样、比较、编码”讲成自己的话。后面学习校准时，所有算法最终都要回到这些非理想来源：采样误差、增益误差、比较器误差、电容/电阻失配、时钟误差和数字拼接误差。

## 进一步展开：指标该怎么背

静态指标可以想象成用很慢的斜坡扫 ADC 输入，然后观察输出台阶。offset 看整体起点偏移，gain error 看整体斜率，DNL 看每个台阶宽度，INL 看台阶边界相对理想直线的累计偏离。

动态指标可以想象成输入一个纯正弦，理想输出频谱应只有基波和白噪声底。真实 ADC 会出现谐波、spur、宽带噪声和 DC 偏移。SNR 只把噪声算进分母，SNDR 把噪声和失真一起算进分母，SFDR 只关心最大单个杂散，THD 只关心谐波族。

不要把 ENOB 当作芯片“真的少了几位”。ENOB 是用 SNDR 反推的等效指标，它把噪声、失真、测试条件都压进一个数字。不同输入频率、幅度、带宽下 ENOB 可以不同。
