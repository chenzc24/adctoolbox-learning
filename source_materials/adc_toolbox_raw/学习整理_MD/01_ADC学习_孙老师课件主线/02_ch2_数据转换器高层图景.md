# ch2 Data Converter High-Level Picture：数据转换器高层图景

## 学习目标

本章要建立最重要的全局图景：现实世界的信号是模拟的，数字系统只能处理符号，ADC 和 DAC 是两者之间的桥。ADC 做的是 a(t) -> d[n]，即时间离散化和幅度离散化；DAC 做的是 d[n] -> a(t)，即把数字序列重新映射成连续时间信号。

## 模拟信号与数字信号

模拟信号通常同时具有两个连续性：时间连续、幅度连续。例如声音压力、电压、电流都可以写成随时间变化的函数。数字信号则是离散时间、离散幅度：它只在某些时刻取值，而且每个取值属于有限集合。

ADC 的本质不是“把模拟变成数字”这么简单，而是做两个近似：

1. 采样：只保留某些时刻的值。
2. 量化：只保留某些幅度区间的编号。

因此 ADC 一定会丢失信息。工程设计的目标不是不丢失，而是让丢失的信息主要落在系统不关心的地方。

## 采样与量化的分工

采样解决时间维度的问题。理想采样可以想象成用冲激函数在固定时刻读取信号。真实电路中冲激采样不可能实现，所以用 track-and-hold 或 sample-and-hold 电路：先跟踪输入，再在某个瞬间保持住电压。

量化解决幅度维度的问题。量化器把连续电压轴切成很多区间，每个区间对应一个 code。N 位 ADC 有 2^N 个可能输出码，因此理想 LSB 宽度约为 full-scale range / 2^N。

## ADC 和 DAC 的互相依赖

很多 ADC 内部其实包含 DAC。例如 SAR ADC 用电容 DAC 产生比较电压；Pipeline ADC 每一级用 sub-DAC 把粗量化结果转回模拟量，再和输入相减得到余差。因此学习 ADC 时不能完全跳过 DAC。

DAC 的非理想会直接变成 ADC 的非理想：电容失配导致权重错误，权重错误导致 INL/DNL，严重时导致 missing code 或非单调。

## 重要直觉

ADC 输出码不是输入电压的精确值，而是“输入电压落在哪个区间”的标签。高位数并不自动意味着高精度，因为如果采样、比较器、参考电压、DAC 权重或时钟有误差，码字标签本身就会偏离真实区间。

## 与校准的连接

如果理想 ADC 的区间边界是已知的，但实际区间边界因为电容失配、增益误差、比较器偏置而发生移动，那么校准的目标就是估计这些移动，并在数字域修正它们。换句话说，校准是在恢复“码字和真实电压之间的映射关系”。

## 和后续学习的连接

读完本章后，不要求记住所有电路细节，但要能把“模拟量如何被采样、比较、编码”讲成自己的话。后面学习校准时，所有算法最终都要回到这些非理想来源：采样误差、增益误差、比较器误差、电容/电阻失配、时钟误差和数字拼接误差。

## 进一步展开：从信息角度看 ADC

模拟信号携带的信息量非常大，因为时间和幅度都连续。数字系统不能保留全部信息，所以 ADC 的工作不是“无损转换”，而是“保留对任务有用的信息”。采样决定时间上保留哪些点，量化决定幅度上保留多少等级。

可以把 ADC 看成三个映射连续发生：物理量到电压、电压到采样值、采样值到码字。传感器和前端电路决定第一步，采样保持决定第二步，比较器和编码逻辑决定第三步。任何一步的误差都会体现在最终数字码中。

Full-scale range、LSB、transition level、code width 是本章之后最常用的四个词。FSR 是整个输入范围，LSB 是理想最小间隔，transition level 是码字切换边界，code width 是相邻边界距离。后面 DNL/INL 全都建立在这套语言上。
