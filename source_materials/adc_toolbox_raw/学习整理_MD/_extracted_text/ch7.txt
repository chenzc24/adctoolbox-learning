          How about Using an Op-Amp?

• Opamp can achieve high gain, but its speed is a problem.
• For an opamp, Av = gmR, w0 = 1/RC  Avw0 = gm/C = Id /C * (gm/Id)
   – gm/Id depends on biasing, but usually around 10~20 V-1
   – For the same Id (power), a direct trade-off between Av and f0

          Comparator Noise Simulation (2)
• Assuming comparator input referred noise follows normal distribution,
  we can estimate comparator noise s based on the following formula:




• Vin = 300uV, P(Dout=1) = 80%  s  350uV
   – In MATLAB, s = Vin /norminv(P,0,1)
• To reduce estimation error, we want to:
   – Simulate more samples
   – Make Vin  s
• Be careful
   – If the comparator has offset (due to post-layout asymmetry), we
      need to take it away first
   – We also need to ensure the comparator is fully reset (no memory
      effect), otherwise there will be correlation between samples, causing
      miscalculations

   – Large noise bandwidth needed

• For a well-optimized comparator, we prefer:
   – Large G: attenuate the noise from the latch stage
        • For Strong-Arm, G is 3~5
   – Large gm/ID: it improves energy efficiency
        • In practice, gm/ID is 10~20 V-1
        • A too-large gm/ID slows down the comparator and increases the
          comparator input capacitance
